🍎 macOS 一键安装 推荐

bash -c "$(curl -fsSL https://lidihong.github.io/zhimeng-releases/install.sh)"
打开「终端」,粘贴上面的命令后回车:自动识别芯片、下载最新版、装入「应用程序」并打开。
不会出现「应用已损坏」,也不会找不到 App。苹果芯片和英特尔芯片都适用。

📦 手动下载

打开软件后,用邮箱 + 邀请码登录;邀请码请向作者索取。
Windows 首次打开若弹 SmartScreen,点「更多信息」→「仍要运行」。
Windows 版首次使用需安装 Python 3.9+(软件内会有引导)。
